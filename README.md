## Fast start
### So, for first:
- 1. Install all needable packages with command ```pip install -r requirements.txt```
- 2. Go to ```.env.example``` in main directory and copy it and past with name ```.env```
- 3. In ```.env``` file paste token of bot to field ```TOKEN```
- 4. Connect bot to your servers!

## About
This bot on start check up all members of guilds that connectet TO ALL your servers and move role that in all this guilds to guilds where they dont have it(so, it dont giving roles that guy dont have at ALL guilds). On deleting or adding role, bot synchronizeing it and same on join to server.
